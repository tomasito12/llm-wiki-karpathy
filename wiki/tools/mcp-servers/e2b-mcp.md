## What problem does this tool solve?

Closing the gap between **code the model writes** and **code that runs**: execute scripts, inspect output, and iterate from inside the assistant loop without touching the local machine or production.

## Properties

- Describes **secure cloud sandbox** execution, isolated from **user device** and **production systems**.
- Example tasks in-source: run analysis and return charts, **test migrations before commit**, run shell commands “safely” off-laptop.
- Product link: [e2b.dev](https://e2b.dev/).
