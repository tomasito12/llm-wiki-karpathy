## What problem does this tool solve?

Letting an assistant query and navigate GitHub **repos, issues, pull requests, and commits** in natural language so developers avoid constant context switching and manual search.

## Properties

- Natural-language examples in-source: bugs labeled over a window, files with most churn, symbol references across the codebase.
- Said to work with **Claude Desktop, Cursor, Windsurf, and VS Code** per the article.
- “Try here” link points to [github.com/modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers).
- Editorial note in-source that **Microsoft** is associated with longevity of the GitHub side (not detailed technically).
