# Lungo

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
A Mac utility that keeps the computer awake when the user needs the screen to stay on.

## Core Capabilities

- It prevents the Mac from sleeping when the user wants the screen to remain active.
- It can be toggled on and off from the icon, which minimizes the steps needed for temporary use.
- It substitutes for manual changes to macOS energy settings in short-term scenarios.
