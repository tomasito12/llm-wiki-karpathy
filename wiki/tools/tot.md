# Tot

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
A tiny menu bar notepad with seven colored dots, each acting as a separate text field.

## Core Capabilities

- It offers seven separate text fields, which lets users keep a handful of quick notes distinct without a larger note hierarchy.
- It stays in the menu bar, making it fast to open for transient capture.
- It is designed for very short inputs rather than full documents, which makes it low friction for on-the-fly thinking.

## Integration Ecosystem

- The source does not mention any integrations, sync services, or export targets.
- Its menu bar placement suggests desktop-only use, but no formal compatibility details are given.

## Maturity signals

The app appears to be a focused, stable utility for a very specific note-taking style. The article's description suggests it has enough staying power to be used daily, but it provides no ecosystem or enterprise signals. As of 2026-04-17, maturity evidence is limited to repeat personal use.

## Related Tools

## Strengths

- Its tiny interface lowers friction for short-lived notes and reference text.
- Separate colored dots create small, persistent slots for different snippets without forcing a file or folder structure.
- The app's lack of sync and folder complexity appears to be a feature, not a limitation, for rapid capture.

## Weaknesses / limitations

The source implies that Tot is intentionally minimal, so it is not suited to long-form note systems, collaboration, or structured organization. There is no evidence of search, export, or synchronization features. It is useful because it is small, not because it is comprehensive.
