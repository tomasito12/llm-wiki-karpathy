# Velja

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
A Mac browser picker that routes links to the right browser manually or by rule.

## Core Capabilities

- It prompts the user to select a browser when a link is opened, which gives immediate context control.
- It supports routing rules so common link types can be sent to the right browser automatically.
- It helps separate work and personal browsing without manual link copying.

## Integration Ecosystem

- The source names Safari, Chrome, and Firefox as browsers used with the app.
- The article does not mention browser extensions, APIs, or enterprise policy integrations.

## Maturity signals

The app is presented as a practical utility with a narrow but recurring use case. The author uses it across Safari, Chrome, and Firefox, which suggests a real workflow fit, but the article does not indicate broader adoption. ## Strengths

- Lets users choose a browser at click time, which is handy when different tasks live in different browser profiles.

- Reduces friction for workflows that separate work and personal browsing contexts.

## Weaknesses / limitations
