# Paste

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
A clipboard manager that stores copied text, images, links, and code snippets so they can be searched and pasted later.

## Core Capabilities

- It preserves clipboard history so older copied material is still available after new copies overwrite the current clipboard.
- It indexes multiple content types, which makes it useful for mixed writing, design, and coding workflows.
- It provides search over history, which turns copied material into retrievable working memory.
