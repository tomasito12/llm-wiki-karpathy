# One Thing

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
A menu bar reminder app that displays a single important item at a time. It is intended to keep one priority visible without becoming a full task manager.

## Core Capabilities

- It keeps one reminder visible in the menu bar until the user clears it.
- It supports styling changes like larger text, bold text, and red text to increase salience.

## Maturity signals

The article treats it as a simple, established utility rather than a high-growth product. As of 2025-12-31, there is no evidence in the source about ecosystem depth or enterprise adoption.

## Strengths

- Keeps one priority visible in the menu bar, which is useful when the user needs a persistent nudge without extra workflow overhead.
- Supports emphasis controls like larger text, bold text, and color, which makes the reminder harder to ignore when needed.
- Avoids the complexity of a task manager, so it can fit into a low-friction desktop setup.

## Weaknesses / limitations

The source does not describe syncing, notification behavior, or multi-item support, so it may be too minimal for users who need richer task tracking. Its usefulness is inherently narrow because it only solves the 'remember one thing' problem.
