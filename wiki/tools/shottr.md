# Shottr

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
A screenshot utility for macOS that adds blurring, scrolling capture, and optical character recognition.

## Core Capabilities

- It can blur sensitive information in screenshots, which supports safer sharing.
- It can capture full scrolling pages, which preserves context in documentation and debugging.
- It can extract text from images, which turns screenshots into reusable source material.

## Maturity signals

Shottr is described as a value-heavy utility rather than a niche experiment, and the price point is explicit. The source gives no adoption data, but the feature set suggests a mature power-user screenshot tool. As of 2026-04-24, the signal is mostly a practical recommendation.

## Strengths

- Combines capture, redaction, scrolling screenshots, and text extraction, which makes it more efficient than using separate tools for each job.
- The ability to blur sensitive details is especially useful when screenshots cross team boundaries.
- Scrolling capture helps preserve full-page context instead of fragmenting evidence across many images.

## Weaknesses / limitations

The source does not describe OCR accuracy, file output options, or whether the redaction is reversible. There is also no comparison against built-in macOS tools beyond the author's opinion.
