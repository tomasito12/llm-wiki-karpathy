## What problem does this tool solve?

Run a **local-first autonomous agent** that uses chat apps as its UI while keeping data on your machine—pitched toward technical users who want automation without sending data to hosted vendors.

## Properties

- Site (author): [open-claw.org](https://open-claw.org).
- Author: **50+ messaging platforms** (WhatsApp, Telegram, Slack, etc.), **persistent memory**, **bash**, file ops, web browsing—all **author claims** to verify.
- Author notes **more involved setup** and **3.8/5 ease-of-use** style framing; **desktop/laptop** emphasis.
