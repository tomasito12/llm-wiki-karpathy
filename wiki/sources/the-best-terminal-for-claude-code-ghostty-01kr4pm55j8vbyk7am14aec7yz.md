# The Best Terminal for Claude Code - Ghostty

This article is about choosing a terminal program that feels fast and pleasant when working with Claude Code. The writer says that on an older Mac, some editing tools felt slow, so they looked for a terminal-based setup instead. They chose Ghostty, which is a terminal app that uses the computer’s graphics hardware to draw text smoothly. The article also says Ghostty starts quickly, uses less memory than some other terminals, and is easy to configure with a plain text file. It supports themes, custom visual effects, and even background images, so the terminal can be easier to look at during long sessions. The author says these things matter because Claude Code can produce a lot of output and require frequent yes-or-no replies. The main recommendation is not that Ghostty is magic, but that it fits this style of work better than heavier terminal choices. The overall advice is practical: if terminal lag bothers your coding flow, Ghostty is worth trying.
