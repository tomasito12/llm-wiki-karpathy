# Knowledge Compilation Over Retrieval

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Some knowledge systems are designed to store and retrieve source material; others are designed to turn source material into a continuously updated compiled workspace. In the compilation approach, each new document is integrated into a persistent structure that can surface contradictions, maintain links, and preserve context across time. This is more demanding than simple search, but it can produce a more coherent working memory for long-lived projects. The operational benefit is fewer one-off queries and more cumulative understanding.

## Key Points

- Compilation-oriented systems prioritize persistent structure over isolated retrieval hits.
- The value comes from integrating new sources into existing context, not from treating each query as independent.
- This approach is especially relevant when contradiction handling and cross-document synthesis matter.

## Operational Insight

When a corpus is meant to grow, the main challenge is not only finding information but continuously integrating it into a living structure that can revise itself as new evidence arrives.
