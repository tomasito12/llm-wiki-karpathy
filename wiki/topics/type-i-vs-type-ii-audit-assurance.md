# Type I vs Type II Audit Assurance

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Type I and Type II audits are two levels of assurance used in control attestation. Type I checks whether controls are designed appropriately at a point in time, while Type II also checks whether those controls operated effectively over a period. This distinction matters because a documented control is weaker evidence than a control that has been observed working over time. In practice, the difference helps buyers judge whether a security report is a static snapshot or a more durable operational signal.

## Key Points

- Type I = design at a point in time.
- Type II = design plus operating effectiveness over time.
- The distinction helps buyers calibrate how much trust to place in an audit report.

## Operational Insight

When assessing a vendor attestation, treat Type II as stronger evidence than Type I because it includes operating effectiveness over time. Use the distinction to decide how much follow-up testing or custom evidence collection is still needed.
