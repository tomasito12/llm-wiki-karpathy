# Attention-Hungry AI Workflows

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Some AI workflows are designed to maximize interaction volume rather than minimize user effort or preserve focus. These workflows encourage follow-up prompts, repeated iterations, and frequent context switching, which can make users feel productive while reducing deep, uninterrupted work. Operationally, the risk is not only wasted time but also a pipeline that rewards artifact generation over outcome completion.

## Key Points

- Tool design can optimize for usage growth rather than task closure.
- More output is not the same thing as more value.
- Stopping rules and outcome checks help counter interaction inflation.

## Operational Insight

When evaluating AI tools, look for interface patterns that nudge people toward more prompts, more outputs, and more sessions. If a workflow repeatedly expands the task instead of closing it, add explicit stopping rules, outcome checks, or usage limits.
