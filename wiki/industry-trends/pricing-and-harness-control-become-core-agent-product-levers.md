# Provider pricing and harness control are becoming core agent product levers

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Agent products are increasingly differentiated by rate limits, burst capacity, memory, grading, orchestration, and verification controls rather than by model name alone. Providers can change user experience materially by adjusting access policy and harness behavior. This trend matters because the effective product boundary is shifting upward from the model API to the surrounding operating envelope.

## Supporting Data Points

- Claude Code 5-hour limits doubled
- Weekly limits left unchanged
- Opus API limits substantially increased
- Managed-agent features discussed as productized harness components
- Claude paid plans now receive monthly API credits equal to the subscription amount.
- OpenAI offered two months of free Codex usage for enterprise customers switching in the next 30 days.
- Anthropic increased Claude Code weekly limits by 50% through July 13.
- Anthropic restricted/reshaped Claude Code usage patterns
- Theo and other builders reported wrapper and high-volume workflow disruption
- The article explicitly recommends provider/model abstraction and BYOK paths
- Gemini 3.5 Flash is priced at three times Gemini 3 Flash.
- Vendor API pricing listed as $1.50/$0.15/$9.00 per million input/cached/output tokens.
- Artificial Analysis found benchmark-run cost higher than Gemini 3.1 Pro.
- Google, Anthropic, and OpenAI are all described as having raised per-token prices on newer flagship and Flash-tier models.

## Time sensitivity

Time-bound as of 2026-05-07 because it is grounded in a specific frontier-lab capacity and product announcement, but the pattern is likely to remain relevant as long as agent products depend on vendor-controlled harnesses and access policy.

## Uncertainty / maturity

The source supports the pattern, but it does not prove that harness control will stay the dominant differentiator across all providers; it also does not quantify how much of the product advantage comes from harness features versus raw model quality.
