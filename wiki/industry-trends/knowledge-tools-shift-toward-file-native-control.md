# Knowledge Tools Shift Toward File-Native Control

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Personal knowledge tools can gain user trust by keeping notes as plain files with version control instead of opaque app-local databases. The pattern favors portability, auditability, and external automation over lock-in. It is especially relevant for products that want to support AI-assisted editing while preserving user ownership of the workspace.

## Supporting Data Points

- Every note is a Markdown file with YAML frontmatter.
- The vault can be versioned with Git.
- The author frames low-friction migration and coexistence as part of the value proposition.

## Time sensitivity

Actionable as of 2026-04-28; this is a product-direction signal rather than a settled market outcome.

## Uncertainty / maturity

The evidence is a single product review, so it shows a plausible design direction rather than broad adoption or market proof.
