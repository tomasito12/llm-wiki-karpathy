# Agentic coding shifts the bottleneck from code generation to context and orchestration

## Interview Insight

### Summary

Daigle frames the AI-era problem at GitHub as broader than better code completion. The harder issue is coordinating code, communications, and organizational context across many tools and actors as agents generate far more output. He argues that the value moves toward systems that can assemble the right context, choose the right action, and keep humans in the loop where needed.

### Why It Matters

As of 2026-06-02, this is a durable design lesson for AI engineering: model quality alone is insufficient when the real bottleneck is context assembly and workflow routing. Teams building coding agents, enterprise copilots, or internal assistants should treat context integration and orchestration as first-class product problems, not add-ons.

### Operational Relevance

Build agent workflows that pull from multiple business systems, reduce them into task-specific context, and then route output into existing operational channels. Favor orchestration layers that can consume GitHub, chat, email, transcripts, and notes rather than standalone chat experiences.

### Service Automation Relevance

Service automation systems face the same bottleneck: the main challenge is not answer generation but combining customer context, policy, and prior interactions before acting. This supports designs that emphasize context aggregation and handoff logic over generic chat front ends.
