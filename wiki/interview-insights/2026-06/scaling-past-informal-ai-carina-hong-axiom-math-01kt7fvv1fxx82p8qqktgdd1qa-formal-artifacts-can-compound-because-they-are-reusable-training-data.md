# Formal artifacts can compound because they are reusable training data

## Interview Insight

### Summary

Carina Hong’s core argument is that a verified proof is not only correct, but also reusable. Once something is proved in Lean, it can be trusted as high-quality data for later training and inference, which lets capability accumulate on top of solid foundations instead of informal rollouts. The transcript frames this as both scaling and compounding intelligence.

### Why It Matters

As of 2026-06-03, this is a useful systems idea for AI teams building knowledge flywheels: verified artifacts can become a durable corpus rather than a one-off output. That shifts the unit of value from a single answer to a validated asset that can be reused across future workflows. The claim is thesis-level, but the data-compounding logic is operationally meaningful.

### Operational Relevance

Design pipelines so outputs that pass verification are stored, versioned, and reused as training or retrieval assets. This is especially relevant for proof assistants, code generation with tests, and any workflow where validated outputs can seed later work. The source suggests that verified outputs can improve both future inference and future training.

### Service Automation Relevance

For service automation, the relevant pattern is storing only validated artifacts as reusable operational knowledge. That could help in compliance-heavy support flows, but only when the underlying task can be specified and checked.
