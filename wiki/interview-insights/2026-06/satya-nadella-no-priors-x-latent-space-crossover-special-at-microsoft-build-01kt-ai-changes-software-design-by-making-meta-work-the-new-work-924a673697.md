# AI changes software design by making meta-work the new work

## Interview Insight

### Summary

Nadella argues that AI does not just automate tasks; it lets organizations reconceptualize work as supervising systems that do the work. He uses the Azure networking example to show a team shifting from performing networking operations to building an agentic system that does networking operations. The insight is that the unit of work moves upward one level.

### Why It Matters

Actionable as of 2026-06-03: teams should look for roles where the highest-value move is to build the system that performs the work, not to keep doing the work manually. This is a durable organizational-design pattern for AI adoption.

### Operational Relevance

Map recurring operational work into agent-managed meta-work, then assign humans to design, inspect, and govern the system. This changes team structure, skill mix, and what counts as output. It also implies new infrastructure around monitoring agent-produced work.

### Service Automation Relevance

Support operations can be redesigned so humans manage the automation system rather than each ticket step. That is relevant for escalations, dispatch, and back-office follow-up where the work is largely coordination and exception handling.
