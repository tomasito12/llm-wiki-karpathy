# Use Spotlight As A Launcher

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Spotlight is macOS's quick access layer for search, launching apps, and small utility actions. The problem it solves is slow, manual navigation through folders and menus. New users often treat it as a basic search box and miss the faster workflow it enables. A keyboard-driven launcher can make the system feel much quicker.

## Caveats

The article mentions multiple modes in macOS Tahoe, but does not explain them in detail. This is a workflow tip, not a measurement of actual system speed.

## Implementation Steps

- Open Spotlight with Command + Space.
- Use it to launch apps instead of browsing folders.
- Try calculator, lookup, and clipboard functions when needed.
- Use Spotlight settings shortcuts to reach system options faster.

## Prerequisites

- Keyboard access
- Spotlight enabled in macOS
