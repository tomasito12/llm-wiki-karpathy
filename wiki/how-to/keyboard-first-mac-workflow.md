# Keyboard-First Mac Workflow

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
A keyboard-first workflow helps people work faster on a Mac by reducing small interruptions from reaching for the mouse or trackpad. It is useful when you do many repetitive actions such as opening files, copying text, or switching between tasks. The main problem it solves is friction: each mouse move breaks concentration and slows down routine work. This approach is especially relevant for users who spend long hours in files, mail, notes, or writing apps.

## Caveats

This is basic macOS advice and not a novel technique. The article is anecdotal and does not measure actual time savings. It is also Mac-specific, so portability is limited.

## Implementation Steps

- Use the Space bar to preview a selected file with Quick Look.
- Use Cmd+C, Cmd+V, Cmd+X, Cmd+A, and Cmd+Z instead of mouse-driven menu actions.
- Treat the mouse or trackpad as the fallback, not the default.
- Practice the shortcuts on repetitive tasks until they become automatic.

## Prerequisites

- A Mac running macOS
- Basic familiarity with keyboard input
- A willingness to replace mouse-driven habits
