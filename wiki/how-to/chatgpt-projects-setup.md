# ChatGPT Projects Setup

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
This is a way to keep related work in one place inside ChatGPT. It solves the common problem of having to re-upload files, repeat instructions, or search through old chats every time you continue a task. It is most useful when a project lasts across several sessions and needs the same background each time. It can also help when more than one person needs access to the same materials.

## Caveats

Sharing depends on plan availability. The article does not specify limits on file size, project size, retention, or how project context interacts with other memory features.

## Implementation Steps

- Open Projects from the left-hand menu.
- Create a new project and give it a name.
- Add files to the project.
- Set project instructions.
- Move existing chats into the project.
- Invite collaborators if sharing is available on your plan.

## Prerequisites

- A ChatGPT account with access to Projects.
- A task that has ongoing context or multiple related files/chats.
- A supported plan if you want to share the project with other people.
