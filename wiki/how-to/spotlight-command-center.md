# Spotlight Command Center

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
A command-center launcher gives you one fast place to start apps, search files, run utilities, and trigger shortcuts. On a Mac, Spotlight can play that role. This helps when you switch tasks often and want to avoid hunting through the Dock or opening multiple apps just to do a small action. The main problem it solves is context switching overhead.

## Caveats

This is a Mac-specific workflow and depends on Spotlight being a good fit for keyboard-oriented users. The article does not compare Spotlight with alternative launchers or measure speed gains. The claimed value is based on personal preference and heavy usage.

## Implementation Steps

- Memorize Cmd+Space as the default way to open Spotlight.
- Use Spotlight to launch apps by typing their names and pressing Enter.
- Add calculations, unit conversions, file search, and system settings lookup into the same habit.
- Create Shortcuts for repeated actions and run them from Spotlight when possible.

## Prerequisites

- A Mac with Spotlight enabled
- Basic knowledge of macOS keyboard shortcuts
- Optional: one or more Shortcuts for repeated actions
