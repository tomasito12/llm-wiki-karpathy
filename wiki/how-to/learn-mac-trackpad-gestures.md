# Learn Mac Trackpad Gestures

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Mac trackpads are built for gesture-based navigation. The problem is that many users rely only on clicking and dragging, which makes the workflow slower than it needs to be. Gestures can reduce mouse dependence and speed up multitasking. This is especially useful on laptops, where the trackpad is already the main pointing device.

## Caveats

Gesture learning has an upfront cost, and the source does not discuss accessibility or preference differences. Some users may still prefer an external mouse for certain tasks.

## Implementation Steps

- Open Trackpad settings in System Preferences.
- Learn app switching gestures first.
- Practice pinch-to-zoom for navigation and browsing.
- Add more gestures gradually as they become familiar.

## Prerequisites

- A Mac trackpad or Magic Trackpad
- Access to Trackpad settings
