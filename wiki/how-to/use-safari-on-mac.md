# Use Safari On Mac

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Safari is Apple's default browser, and the article argues that it fits macOS better than Chrome for many users. The problem is browser choice that adds unnecessary memory use or battery drain on a laptop. New Mac users often default to Chrome out of familiarity, even when the built-in browser may be a better system match. This advice is about choosing the browser that works with the platform instead of against it.

## Caveats

This is a subjective comparison with no metrics in the source. Browser choice should still depend on extensions, workflows, and site compatibility.

## Implementation Steps

- Set Safari as your first browser to test on macOS.
- Compare battery use and responsiveness against Chrome for your usual sites.
- Use Picture-in-Picture where it helps your workflow.
- Keep Chrome only if you need features or compatibility Safari does not provide.

## Prerequisites

- A Mac with Safari installed
- A browser workflow you can compare across apps
