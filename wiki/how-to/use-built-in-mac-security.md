# Use Built-In Mac Security

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Many new Mac users add third-party antivirus software out of habit. The problem is that some people use extra security tools for everyday use even when the operating system already includes built-in protections. That can create unnecessary slowdown, memory use, and alert noise. A simpler setup can be easier to manage if the built-in controls are enough for the user's risk level.

## Caveats

The source makes broad claims and does not define threat models, enterprise controls, or high-risk environments. Users with stricter security requirements may still need additional tools, so this is best treated as default advice rather than a hard rule.

## Implementation Steps

- Review the built-in macOS protections first.
- Turn on the built-in firewall.
- Avoid installing third-party antivirus software unless you have a specific need.
- Reassess security tooling based on your actual risk profile.

## Prerequisites

- A Mac with macOS security features enabled
- A clear sense of whether you have special security requirements
