# Use Preview For Common Tasks

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Preview is the built-in Mac app for opening and working with images and PDF files. The problem it solves is unnecessary software sprawl: many users install extra apps for jobs that the operating system already handles well. That adds clutter and can make a new machine feel heavier than it needs to be. Using the default app can be enough for many everyday document tasks.

## Caveats

Preview is useful for common tasks, but it is not a full replacement for specialized image or PDF editors. The source does not define where its limits begin, so users with advanced editing needs may still need dedicated software.

## Implementation Steps

- Open images and PDFs in Preview first.
- Use annotation tools for basic markup.
- Merge PDF files inside Preview when needed.
- Crop or rotate images without installing extra software.

## Prerequisites

- A Mac with Preview installed
- Basic file-opening workflow
