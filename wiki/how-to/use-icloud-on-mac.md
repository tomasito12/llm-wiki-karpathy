# Use ICloud On Mac

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
iCloud ties together identity, sync, backups, and device tracking on macOS. The problem it solves is fragmentation: without it, parts of the Apple ecosystem stop working cleanly and recovery gets harder if a device is lost. New users sometimes skip it because they think of it as optional storage, but the source treats it as a core account layer. That matters because several system services depend on it.

## Caveats

The source presents iCloud as effectively required, which is stronger than the underlying evidence in the text. Some users intentionally minimize cloud coupling, so this advice is best read as an ecosystem-default recommendation.
