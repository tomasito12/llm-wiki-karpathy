# Keyboard Window Management

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Keyboard-based window management helps you keep the screen organized without constantly dragging windows with a mouse. It matters when you work with several apps at once and need to move between them quickly. The problem is not just clutter; manual resizing and positioning create tiny delays that add up across the day. A consistent window layout can make it easier to stay oriented while switching tasks.

## Caveats

The built-in window controls and third-party tools may behave differently across apps. The save-dialog drag trick may not work uniformly in every file picker, and the article does not test edge cases. The article is written from personal experience rather than controlled comparison.

## Implementation Steps

- Decide on a small set of window layouts you use often.
- Use macOS window shortcuts or a tool like Rectangle to snap windows into place.
- Prefer keyboard shortcuts over manual dragging whenever possible.
- When saving or uploading, drag a file from the target Finder folder into the save dialog to jump there quickly.

## Prerequisites

- A Mac running macOS
- Either the built-in window shortcuts or a window manager such as Rectangle
- A Finder window already open to the desired folder for the drag trick
