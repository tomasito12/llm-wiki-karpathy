# Keep macOS Updated

## Current understanding

<!-- stage1-placeholder: single-source lead; Stage 2 will synthesize from accumulated EvidenceItems -->
Keeping macOS updated is a basic maintenance habit that protects performance and security. The problem is that some users postpone updates until they become a nuisance, which can leave the system missing fixes and optimizations. New Mac users may not realize that updates can affect both stability and battery life. Regular updates reduce the chance of avoidable bugs and security gaps.

## Caveats

The source does not distinguish minor updates from major upgrades, or explain how to handle compatibility checks and backups. Update timing should still be managed around important work.

## Implementation Steps

- Open System Preferences and go to Software Update.
- Enable automatic updates.
- Review update notifications instead of ignoring them.
- Install updates after checking that your setup can tolerate them.

## Prerequisites

- Administrative access to Software Update settings
- A plan for update timing
