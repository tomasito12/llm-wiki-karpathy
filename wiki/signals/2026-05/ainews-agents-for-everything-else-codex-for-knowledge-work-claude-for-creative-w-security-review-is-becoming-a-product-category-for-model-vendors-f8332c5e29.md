# Security review is becoming a product category for model vendors

## Signal

### Summary

Anthropic launched Claude Security as a code review tool that validates findings and suggests fixes, while Cursor shipped Cursor Security Review with always-on PR review and scheduled scans. This is a clear sign that model vendors are moving into security tooling, not just foundation-model APIs. For operators, that means security review may become bundled into broader developer and agent platforms.

### Why It Matters

As of 2026-05-01, the interesting part is not the branding but the category shift: security scanning is being productized as an AI-native workflow. The source does not show comparative accuracy or enterprise adoption, so the claim should be treated as a packaging trend rather than a settled replacement for existing devsecops tools.

### Operational Relevance

This matters for agent builders because code-generation systems will increasingly be judged on review, validation, and fix suggestion loops. It also increases the importance of human verification and false-positive handling in automated security pipelines.

### Service Automation Relevance

Indirectly relevant: security review automation may reduce manual triage load in engineering teams, but there is no direct support-automation evidence in the source.
