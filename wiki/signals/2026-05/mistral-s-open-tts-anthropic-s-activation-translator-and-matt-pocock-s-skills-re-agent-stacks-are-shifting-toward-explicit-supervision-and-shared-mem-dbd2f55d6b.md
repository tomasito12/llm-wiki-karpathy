# Agent stacks are shifting toward explicit supervision and shared-memory critique

## Signal

### Summary

Several roundup items point to the same workflow pattern: agents are being composed into structured loops with critique, memory, and human gates rather than left as single-pass chat systems. CORAL has four agents propose, critique, and preserve only what survives shared-memory review; Paul Iusztin's setup routes work through six Claude Code agents with separate responsibilities and two human gates; Agent-World uses verifiable tasks and RL on failures; and Matt Pocock's skills repo packages reusable workflow rules. As of 2026-05-17, the durable signal is that agent performance is increasingly a harness and supervision problem, not just a prompting problem.
