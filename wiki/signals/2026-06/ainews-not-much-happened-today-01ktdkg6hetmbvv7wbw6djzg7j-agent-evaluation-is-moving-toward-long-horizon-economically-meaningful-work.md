# Agent evaluation is moving toward long-horizon, economically meaningful work

## Signal

### Summary

The roundup highlights benchmarks that go beyond short coding tasks and simple pass/fail prompts. Agents' Last Exam maps more than 1,000 tasks to occupational taxonomy, and SWE-Marathon tests coherence over billion-token budgets. This matters because evaluation is becoming closer to real work rather than isolated toy tasks.

### Why It Matters

As of 2026-06-06, teams building agents should expect evaluation to focus more on sustained task completion, not only narrow benchmark scores. That changes how products are tested, instrumented, and compared.

### Operational Relevance

Prioritizes long-horizon task harnesses, task decomposition, and failure tracking over single-turn accuracy metrics.

### Service Automation Relevance

Relevant for support and back-office automation because service tasks often require multi-step completion, not one-shot answers.

### Evidence Snippets

- Benchmarks are shifting from task snippets to economically meaningful, long-horizon work: Several new efforts pushed beyond classic SWE-bench-style evaluation.
- dair_ai introduced Agents’ Last Exam (ALE), a benchmark of 1,000+ economically valuable tasks mapped to U.S. occupational taxonomy, with the hardest tier averaging just 2.6% full pass rate.
- rishi_desai2 launched SWE-Marathon, testing whether coding agents can stay coherent over 1B-token budgets.
