# Browser prompts becoming reusable workflows

## Signal

### Summary

Google's Chrome 'Skills' turns prompts into one-click actions that run against the current page and selected tabs. The notable change is that a prompt is no longer just remembered text; it becomes a reusable browser workflow with a library of saved actions. That makes the browser itself a lightweight automation layer.

### Why It Matters

This matters because it turns prompt design into workflow design, which is a more durable abstraction for product teams building agentic interfaces.

### Operational Relevance

Teams building browser assistants, research tools, or task automation products should think about saved actions, page context, and repeatability rather than only prompt quality.

### Service Automation Relevance

This could reduce friction in browser-based support operations, internal lookup tasks, and repetitive admin work where the same actions recur across pages.
