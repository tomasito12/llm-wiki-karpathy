# Frontier evaluation moving beyond saturated coding benchmarks

## Signal

### Summary

The roundup says SWE-Bench is saturated and points to new efforts like Notion's Last Exam, ARC-AGI-3, and next-frontier coding evals. The underlying signal is that common software-engineering benchmarks are losing differentiation value for some audiences. That pushes evaluation toward harder, more task-specific, or more adversarial tests.

### Why It Matters

This matters because once a benchmark saturates, it stops being a useful product-selection or progress signal and teams need new evals to preserve decision quality.

### Operational Relevance

Teams should expect more bespoke evaluation suites for coding, agents, and knowledge work rather than relying on one public leaderboard.

### Service Automation Relevance

Service automation systems need evals that reflect real task completion, not just generic benchmark performance, so this trend supports custom harnesses for support workflows.
