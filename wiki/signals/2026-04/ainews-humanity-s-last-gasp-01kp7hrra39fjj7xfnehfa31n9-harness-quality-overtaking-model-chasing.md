# Harness quality overtaking model chasing

## Signal

### Summary

The piece argues that agent performance depends heavily on the scaffold around the model. It highlights task-specific open harnesses, workflow design, memory switching, and tool output control as recurring differentiators. The practical message is that model selection alone is an incomplete optimization target for agent systems.

### Why It Matters

This matters because many agent failures are harness failures, not model failures, and that changes how teams should allocate engineering effort.

### Operational Relevance

Evaluation, prompt routing, memory policy, and tool-output shaping are likely to dominate real performance gains in production agent systems.

### Service Automation Relevance

For support automation, better harnesses can improve consistency, reduce hallucinated actions, and make human handoff easier to control.
